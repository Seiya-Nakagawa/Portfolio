## 1. 概要

Issue #171 の対応。サービス紹介ページ、利用規約・プライバシーポリシー（版ごとのテンプレート）、問い合わせ窓口への
リンクを作成し、管理画面に初回利用の案内を表示する。設計は
[基本設計書 5.1.3](../02.design/DESIGN.md#513-サービス共通)・
[5.3.3](../02.design/DESIGN.md#533-サービス共通) を参照する。

## 2. 前提条件

- 問い合わせ窓口の Google フォームを作成済みであること（フォームの URL を 3.4 で設定する）
- 規約・プライバシーポリシーの本文の内容を、運営者が確認し承認していること

## 3. 手順

### 3.1. 職務経歴書の出力例の画像の作成

実データを含めないため、架空のデータで作成する。

1. 一時的なデータベース（テスト用設定のメモリ上の SQLite）に、架空の会社・案件・スキル・資格・文章項目を登録し、
   アプリの職務経歴書の生成処理（`portfolio.export.render_skillsheet`）で HTML を生成する。氏名には「（架空）」を付ける
2. 生成した HTML を一時的な HTTP サーバーで配信し、ブラウザー（幅 860px・高さ 1100px）で開いて、画面全体の
   スクリーンショットを撮る
3. スクリーンショットを `webapp/static/img/skillsheet-sample.png` に配置する
4. 一時的な HTTP サーバーを停止し、生成した HTML・スクリーンショットの一時ファイルを削除する

### 3.2. 規約の本文の確認

1. `webapp/templates/legal/terms/{版}.html`・`webapp/templates/legal/privacy/{版}.html` の本文を確認する
   - 運営者の氏名・連絡先等の個人情報を記載しない
   - プライバシーポリシーに、バックアップの保持期間（日次 30 世代・月次 12 世代、退会後のデータが残る最大約 12 か月）が
     記載されていること
2. 版の定数（`TERMS_VERSION`・`PRIVACY_VERSION`）が、本文のテンプレートのファイル名と一致していること

### 3.3. ローカルでの動作確認

```bash
uv run python manage.py runserver
```

1. `/` にサービス紹介が表示され、出力例の画像とログインボタンがあること
2. `/terms/`・`/privacy/` が表示され、版が記載されていること
3. サービス紹介・規約・ログイン・公開ポートフォリオのフッターに、利用規約・プライバシーポリシー・お問い合わせ
   （`CONTACT_FORM_URL` を設定した場合）のリンクがあること
4. 案件が 1 件もないユーザーで登録画面を開くと、「案件登録」に初回利用の案内が表示されること

### 3.4. 本番への適用

1. マージ前に、Vault ではなく ConfigMap（`k8s/configmap.yaml`）へ `CONTACT_FORM_URL: "{Google フォームの URL}"` を追加する
   （フォームの URL は秘密情報ではない）
2. マージ後の CD の完了後、`https://skillsheet.technohonesty.com/` と各ページが表示されることを確認する
