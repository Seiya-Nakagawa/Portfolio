## 1. 概要

Issue #52 の対応として、旧構成（GAS ウェブアプリ・GitHub Pages・実績シート）を廃止する。
実績データの移行は [13 実績シートの過去実績の移行](13_実績シートの過去実績の移行.md) で実施済みである。

## 2. 前提条件

- ポートフォリオアプリが `https://technohonesty.com/portfolio` で稼働していること
- 実績 DB の経験年数・表示内容が旧サイトと一致することを確認済みであること

## 3. 手順

### 3.1. GAS 関連ファイルの削除

```bash
git rm -r gas
rm -f .clasp.json
```

- `gas/` 配下の GAS コードをリポジトリから削除する
- `.clasp.json` のローカルファイルを削除する（`.gitignore` の該当行も削除する）

### 3.2. GAS ウェブアプリのデプロイ停止

1. Apps Script エディタで対象プロジェクトを開く。
2. 「デプロイ」→「デプロイを管理」で、ウェブアプリのデプロイをアーカイブする。

### 3.3. GitHub Pages の無効化

```bash
gh api -X DELETE repos/seiya-nakagawa/Portfolio/pages
```

- リポジトリの GitHub Pages 公開を無効化する

### 3.4. 実績シートのアーカイブ

1. Google ドライブで実績シート（スプレッドシート）を、アーカイブ用フォルダへ移動する。
2. 編集権限を閲覧のみへ変更する。
