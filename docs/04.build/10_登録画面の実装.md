## 1. 概要

Issue #49。[基本設計書](../02.design/DESIGN.md)に基づき、GAS ウェブアプリの機能を
ポートフォリオアプリの登録画面（`/manage/`）として実装する。案件登録・スキル項目管理・
資格・実績管理・職務経歴書エクスポートの 4 画面を、ログイン後の 1 ページ上のタブで切り替える。

## 2. 前提条件

- [09 構築手順書](09_公開ページ配信と読み取り専用APIの実装.md)が完了していること
- `webapp/` で `uv sync` 済みであること

## 3. 手順

### 3.1. 認証設定

1. `config/settings/base.py` に `LOGIN_URL`（`login`）・`LOGIN_REDIRECT_URL`（`manage`）・
   `LOGOUT_REDIRECT_URL`（`index`）を追加する。認証は Django 標準の認証機能を使い、
   本人 1 名のみのユーザーを作成する。
2. `config/settings/production.py` に、セッション・CSRF の Cookie を HTTPS 限定にする設定
   （`SESSION_COOKIE_SECURE`・`CSRF_COOKIE_SECURE`）と、環境変数 `CSRF_TRUSTED_ORIGINS`
   （Ingress で終端された HTTPS のオリジン）を追加する。

### 3.2. 書き込み処理と入力値検証の作成

`portfolio/registry.py` を作成する。

- 案件の保存: 案件名・開始年月・終了年月の形式と前後関係、スキル項目の存在・重複・バージョン長を
  検証する。更新時は対象案件の行をロックし、`project_skills` を削除してから登録し直す。
- 案件の削除: 対象案件の行をロックして削除する（紐づく `project_skills` も削除される）。
- スキル項目・資格・実績の追加・変更・削除: モデルの検証（`full_clean`）でサーバー側の検証を行う。
  スキル項目は `skill_id` を変更不可とし、使用実績が紐づく項目の削除を拒否する。
- 書き込みはすべて `transaction.atomic()` 内で対象行を `select_for_update()` でロックする。

### 3.3. 職務経歴書エクスポートの作成

`portfolio/export.py` を作成する。

- `■テクニカルスキル` の表（種類・項目・開始年・使用期間・レベル）と、`■開発経歴` の案件期間
  （開始年月の昇順）を、空行 1 行で区切った Markdown として生成する。
- 使用実績がなく出力対象外のスキル項目の件数と、`levels` に存在しない `level` を持つ
  スキル項目の一覧を警告として返す。

### 3.4. ビューと URL の作成

1. `portfolio/manage_views.py` に、ページ（`index`）と JSON API を作成する。
   ページはログイン必須（未ログインはログイン画面へリダイレクト）、API は未ログインで 401 を返す。
   検証エラーは 400、対象なしは 404 を返す。
2. `config/urls.py` に `manage/` 配下の URL（ログイン・ログアウト・ページ・API・
   エクスポートのダウンロード）を追加する。

### 3.5. 画面の作成

1. `templates/manage/login.html`・`templates/manage/index.html` を作成する。
2. `static/css/manage.css` を作成する。
3. `static/js/manage.js` を作成する。
   - 案件登録: 継続中の案件の選択・新規作成・ページタブ（案件情報・カテゴリ・確認）・戻る/次へ・
     バージョン入力・保存・削除（確認ダイアログ）を、選択状態をメモリ上に保持したまま実装する。
     「次へ」は案件情報の必須項目（案件名・開始年月）を満たさない場合に進めず、
     保存時にも必ず確認して未入力なら案件情報ページへ戻す。
   - スキル項目管理・資格・実績管理: 一覧・追加・変更・削除の共通画面を実装する。
   - エクスポート: Markdown のプレビュー・ダウンロード・クリップボードへのコピー・警告を表示する。

### 3.6. テストと静的解析

`portfolio/tests/test_manage.py` に、認証（未ログインの拒否・CSRF）・入力値検証・
案件の保存/更新/削除・スキル項目の削除制限・エクスポートの形式のテストを作成し、実行する。

```bash
SECRET_KEY=test uv run python manage.py test --settings=config.settings.test
uv run ruff check .
uv run ruff format --check .
```

- ユニットテストを SQLite（メモリ）で実行する。
- lint とフォーマットの指摘がないことを確認する。

### 3.7. ログインユーザーの作成

マイグレーション適用後、本人のログインユーザーを作成する。

```bash
uv run python manage.py createsuperuser
```

- ユーザー名・パスワードを対話入力して作成する。パスワードはコマンドライン引数・
  リポジトリに記載しない。
