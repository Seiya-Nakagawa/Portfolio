## 1. 概要

Issue #51。[基本設計書 6.5](../02.design/DESIGN.md#65-職務経歴書ビルダーとの責務分担)に基づき、
職務経歴書ビルダー（`tools/skillsheet-builder/`）が読み込む Markdown の出典を、
GAS ウェブアプリの出力からポートフォリオアプリのエクスポートに切り替える。

## 2. 前提条件

- [10 構築手順書](10_登録画面の実装.md)が完了し、ポートフォリオアプリの職務経歴書エクスポートが
  利用できること
- ビルダーのセットアップ（`wkhtmltopdf`・日本語フォント・Python 依存パッケージ）が完了していること

## 3. 手順

### 3.1. ビルダーの変更

`tools/skillsheet-builder/build_pdf.py` から GAS・実績シートへの言及を除く。

- オプション `--gas-output` を `--export` に変更する。
- 関数名を `parse_gas_output`・`apply_gas_output` から `parse_export`・`apply_export` に変更する。
- コメント・ヘルプ・エラーメッセージの表記を「ポートフォリオアプリのエクスポート」に合わせる。

差し替えの仕様（`■テクニカルスキル` の表全体と、案件見出し行の期間部分のみを差し替える）と
入力形式（スキル表・空行 1 行・案件期間の行）は変更しない。

### 3.2. サンプルと README の更新

1. `sample/gas_output.txt` を `sample/export.md` に改名し、内容をエクスポートの形式
   （スキル項目ごとの行）に更新する。
2. `README.md` の構成図と「実績シート（GAS ウェブアプリ）の出力との統合」の節を、
   ポートフォリオアプリのエクスポートを前提とした内容（`--export` の使い方）に更新する。

### 3.3. 動作確認

ポートフォリオアプリのエクスポートで出力した Markdown を指定して PDF を生成する。

```bash
cd tools/skillsheet-builder
python build_pdf.py --export /path/to/export.md
python build_pdf.py --export sample/export.md
```

- エクスポートの表と案件期間で差し替えた PDF が生成されることを確認する。
- マスターデータに対応する見出しがない案件がある場合は、標準エラー出力に警告が表示され、
  PDF 生成が継続されることを確認する（`sample/export.md` で確認できる）。
