## 1. 概要

Issue #97〜#102 の対応として、管理画面の画面遷移・完了通知・確認画面の改善、実績画像のアップロード、
公開画面のヘッダー日本語化、資格の並び順変更を反映する。
実績画像は git 管理から外し、OCI ホストの保存領域へ配置する。

## 2. 前提条件

- ポートフォリオアプリが `https://technohonesty.com/portfolio` で稼働していること
- OCI ホストへ SSH 接続できること
- ローカルの `webapp/media/works/` に既存の実績画像（`portfolio.png`・`blog_link_checker.jpg`・`train_delay_alert.jpg`）があること

## 3. 手順

### 3.1. 既存の実績画像の保存領域への配置

```bash
ssh seiya@217.142.230.83 "sudo mkdir -p /var/lib/portfolio/media/works"
```

- OCI ホストに画像の保存領域とサブディレクトリを作成する

```bash
scp webapp/media/works/* seiya@217.142.230.83:/tmp/
ssh seiya@217.142.230.83 "sudo mv /tmp/portfolio.png /tmp/blog_link_checker.jpg /tmp/train_delay_alert.jpg /var/lib/portfolio/media/works/"
```

- ローカルの画像をホストへ転送し、保存領域へ移動する
- Pod 起動時の初期化コンテナが、保存領域の所有者をアプリケーションのユーザーへ変更する

### 3.2. デプロイ

```bash
./deploy-oci.sh
```

- イメージのビルド、マニフェストの適用（保存領域のマウントを含む）、マイグレーションを実行する

### 3.3. 動作確認

1. 公開画面で、ヘッダー・セクション見出しが日本語で表示され、資格が取得年月の古い順に並ぶことを確認する。
2. 公開画面の実績カードにサムネイル画像が表示されることを確認する。
3. 管理画面の実績で画像を選択し、プレビュー表示・確認画面を経て保存できることを確認する。
4. 保存・更新時に完了通知がポップアップで表示されることを確認する。
5. サイト情報で表示 → 編集 → 確認の順に遷移し、確認画面に変更した項目の修正前後のみが表示されることを確認する。

- 共有 Ingress の最大リクエストサイズが 5MB 未満の場合は、画像のアップロードが失敗するため
  infra-oci 側で上限を調整する
