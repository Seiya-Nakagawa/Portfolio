## 1. 概要

Issue #27。`tools/skillsheet-builder/` を、実績シート（GAS ウェブアプリ）が出力する
`■テクニカルスキル` 表と `■開発経歴` の案件期間を取り込む構成に変更する。

## 2. 前提条件

- [基本設計書 6.5](../02.design/DESIGN.md#65-職務経歴書ビルダーとの責務分担)で職務経歴書ビルダーとの
  責務分担が確定していること
- [05_GASウェブアプリの実装と過去実績の初期登録](05_GASウェブアプリの実装と過去実績の初期登録.md)
  により、実績シートに案件実績が登録済みで、出力タブから Markdown を取得できること
- 職務経歴書マスタ（`master.md`）の `■開発経歴`・`■副業` 等の案件見出し行が、実績シートの
  `projects` シートの `name` と一致していること

## 3. 手順

### 3.1. 実績シートの出力を取得する

1. 実績シートの GAS ウェブアプリを開き、出力タブで Markdown をコピーする。
2. コピーした内容を、職務経歴書マスタと同じローカル環境上のファイル（例:
   `~/skillsheet/gas_output.md`）に保存する。

### 3.2. PDF を生成する

```bash
cd tools/skillsheet-builder
. .venv/bin/activate
python build_pdf.py --input ~/skillsheet/master.md --gas-output ~/skillsheet/gas_output.md --output ~/skillsheet/output/職務経歴書.pdf
```

- `--gas-output` を指定すると、`master.md` 自体を書き換えず、PDF 生成時にのみ
  `■テクニカルスキル` 表と案件見出し行の期間部分を出力内容へ差し替える

### 3.3. 差し替え結果を確認する

1. 標準エラー出力に警告が表示されていないか確認する。表示された場合、実績シート側の
   案件名と、職務経歴書マスタの案件見出し行の名称が一致しているか確認する。
2. 生成された PDF を開き、`■テクニカルスキル` 表の使用期間と、`■開発経歴`・`■副業` の
   各案件見出しの期間が実績シートの内容と一致していることを確認する。
3. 案件概要・業務内容等の本文が変更されていないことを確認する。
