## 1. 概要

- 対応 Issue: [#8](https://github.com/Seiya-Nakagawa/Portfolio/issues/8)
- 職務経歴書のビルド機構を、架空のダミーデータを同梱した汎用ツールとして
  `tools/skillsheet-builder/` に公開する。公開対象は仕組みのみとし、実データは含めない

## 2. 前提条件

- [#6](https://github.com/Seiya-Nakagawa/Portfolio/issues/6) によりリポジトリが public になっていること
- [#7](https://github.com/Seiya-Nakagawa/Portfolio/issues/7) によりローカル運用（`~/skillsheet/`）が
  立ち上がり、`build_pdf.py` の動作が確認できていること
- `wkhtmltopdf`、日本語フォント（`fonts-noto-cjk`）が導入済みであること

## 3. 手順

### 3.1. tools/skillsheet-builder/ を作成する

- ローカル運用中の `~/skillsheet/build_pdf.py` をベースに、実データへの依存を持たない形へ整理し
  `tools/skillsheet-builder/build_pdf.py` として配置する
  - 入出力パスを `--input` / `--output` 引数で指定できるようにし、デフォルト値は
    同梱のサンプルデータ（`sample/master.md`）を参照する形にする
- `requirements.txt`（`Markdown>=3.7`）を配置する
- `sample/master.md` に、架空の氏名・企業名・案件内容によるサンプルデータを作成する
- セットアップ手順・実行方法を記載した `README.md` を作成する
- ビルド生成物（`output/`）と Python 仮想環境（`.venv/`）をリポジトリのルート `.gitignore` に追加する

### 3.2. サンプルデータのみでビルドが完走することを確認する

```bash
cd tools/skillsheet-builder
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python build_pdf.py
```

- `output/職務経歴書.pdf` が生成されることを確認する

### 3.3. 実データ由来の記述が混入していないことを確認する

- `sample/master.md` に実在の企業名・案件名・個人名が含まれていないか、
  `~/skillsheet/master.md` の固有名詞と突き合わせて確認する
- コミット前に `git diff` の差分を目視確認する

### 3.4. ポートフォリオサイトの実績一覧へ追加する

- `js/data.js` の `worksData` に、本ツールを紹介するエントリを追加する
  - `github_url` は本リポジトリの `tools/skillsheet-builder/` へのリンクとする

### 3.5. 設計文書へ位置づけを追記する

- [`docs/DESIGN.md`](../DESIGN.md#8-職務経歴書の管理方式) の「8. 職務経歴書の管理方式」に、
  公開ツールの README への参照リンクを追記する
