## 1. 概要

- 対応 Issue: [#13](https://github.com/Seiya-Nakagawa/Portfolio/issues/13)
- ヘッダーのナビゲーションがビューポート中央ではなく左寄りに表示される問題と、
  ナビゲーションリンクの文字サイズが小さい問題を修正する

## 2. 前提条件

- 特になし

## 3. 手順

### 3.1. header と nav の役割を分離する

- `index.html` の `<header class="container">` から `container` クラスを外し、
  子要素の `<nav>` に `container` クラスを付与する
  - `header` は `position: fixed; left: 0; width: 100%;` によりビューポート全幅に
    固定表示する役割のみを持つ
  - `container` クラス（`max-width: 1200px; margin: 0 auto;`）による中央寄せは
    `nav` 側で行う
  - 同一要素に「全幅固定」と「中央寄せの `max-width`」を両方指定すると、
    `position: fixed` の左右方向の解決アルゴリズム上 `margin: auto` が効かず
    左端に寄って表示されるため、役割ごとに要素を分ける

### 3.2. ナビゲーションリンクの文字サイズを調整する

- `css/style.css` の `.nav-links a` に `font-size: 1.1rem;` を追加し、
  ロゴ（`.logo` の `1.5rem`）とのバランスを調整する

### 3.3. デスクトップ・タブレット・モバイル幅で表示を確認する

- Playwright の headless Chromium でビューポート幅 1560px・1024px・375px の
  スクリーンショットを取得し、以下を確認する
  - ナビゲーション（ロゴ・リンク一式）が他セクションと同じ中央寄せ幅で表示されること
  - モバイル幅（768px 以下）でハンバーガーメニューアイコンが右端に表示されること
