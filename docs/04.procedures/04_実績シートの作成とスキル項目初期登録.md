## 1. 概要

Issue #24。基本設計で確定したシート構成に従い実績シートを作成し、スキル項目・案件の初期登録を行う。

## 2. 前提条件

- [基本設計書 4章](../02.design/DESIGN.md#4-データ設計)でシート構成が確定していること
- 実績シートの配置先となる Google アカウントを保有していること

## 3. 手順

### 3.1. スプレッドシートの作成

1. 本人の Google ドライブ上に新規の Google スプレッドシートを作成し、タイトルを「実績シート」とする。

### 3.2. シート構成の反映

1. 作成したスプレッドシートに、[基本設計書 4.2](../02.design/DESIGN.md#42-シート構成)の5シートをタブとして作成する。

   - `skills`
   - `projects`
   - `monthly_skills`
   - `monthly_projects`
   - `levels`

2. 各シートの1行目に、対応するヘッダー行を入力する（[基本設計書 4.3〜4.7](../02.design/DESIGN.md#43-skillsスキル項目マスタ)参照）。

   | シート名 | ヘッダー行 |
   | --- | --- |
   | `skills` | `skill_id`, `category`, `name`, `level`, `remarks`, `sort_order` |
   | `projects` | `project_id`, `name`, `sort_order` |
   | `monthly_skills` | `year_month`, `skill_id` |
   | `monthly_projects` | `year_month`, `project_id` |
   | `levels` | `level`, `portfolio_label`, `resume_label` |

3. `monthly_skills.year_month` と `monthly_projects.year_month` の列の表示形式を「書式なしテキスト」に設定する。
