案件を登録するだけで、
職務経歴書が完成する。

案件ごとに使ったスキルを登録すると、経験年数を自動で算出し、職務経歴書の PDF や Markdown を、いつでも最新の内容で出力できます。

{% if user.is_authenticated %} スキル実績管理へ {% else %} Google / GitHub で始める {% endif %}

特長

経験年数の自動算出

案件の期間と使用したスキルから、スキルごとの経験年数を自動で計算します。並行して進めた案件も重複せずに数えます。

職務経歴書 PDF の自動生成

会社・案件・資格・自己PR から A4 の職務経歴書を組み立てます。更新するたびに、最新の内容で PDF や Markdown を取得できます。

案件・スキル・資格の一元管理

会社・案件・スキル・資格を 1 か所にまとめて登録できます。登録した内容は、職務経歴書の更新のたびに再入力せず使い回せます。

利用の流れ

  1. ログインGoogle または GitHub のアカウントでユーザー登録します。パスワードは不要です。
  2. 案件を登録会社と案件を登録し、案件ごとに使ったスキルを選びます。
  3. 職務経歴書を取得職務概要や自己PR を入力して、プレビューを確認し、PDF をダウンロードします。

職務経歴書の出力例

架空のデータで作成した出力例です。
